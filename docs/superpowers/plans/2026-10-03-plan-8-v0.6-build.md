## Global Constraints

- No agent runs `git commit`, `git push`, `git stash`, `git checkout`, `git switch`, `git reset`, or `git rebase`. The orchestrating session commits. No agent posts outside the project.
- Docs in ASD-STE100, as the spec. Code comments and messages in plain English.
- Each new decision carries "Owner decision <date>" or "Agent-derived, needs owner decision". An untagged decision is a defect.
- Docs and code ship in one pull request.
- The push, the pull request, the merge, and the release each need an explicit go of the owner.
- The committed files contain no personal names, host names, or machine paths.
