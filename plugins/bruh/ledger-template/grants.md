# Merge grants

Every merge is a P1 to the owner, except under a grant in this file. A grant names the merger clerk `clerk-<project>-merge` and its conditions for one repository. Only the owner gives a grant, explicitly. bigm records it here with the words of the owner. One merger acts for each repository at a time. A merge is confirmed by a read of the code host API, never by an exit code.
